# Bean-brew
(Пример работы для портфолио)
Bean &amp; Brew — лендинг кофейни
Одностраничный сайт для кофейни в центре Москвы. Сделан на чистом HTML, CSS и ванильном JavaScript — без фреймворков, сборщиков и внешних библиотек.


## Что внутри

- **Hero-секция** с анимированным градиентом и появлением заголовка по буквам
- **Меню-аккордеон** на нативных `<details>` — 3 категории, 16 позиций с ценами
- **Мобильный бургер** без JavaScript (checkbox hack)
- **Плавное появление блоков** при скролле через `IntersectionObserver`
- **Sticky-шапка** с изменением фона при прокрутке
- **Адаптив** под iPhone и Android

## Стек

- HTML5 (семантическая разметка)
- CSS3 — переменные, Grid, Flexbox, keyframes-анимации
- JavaScript — ~80 строк, только для анимации аккордеона, `IntersectionObserver` и смены шапки
- Google Fonts: Fraunces, Inter, Space Mono

## Запуск

Никаких сборок и зависимостей. Достаточно открыть `index.html` в браузере.
